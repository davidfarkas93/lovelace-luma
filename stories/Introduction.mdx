# Luma

A vibrant, context-aware Lovelace card suite for Home Assistant.

This catalogue runs the same Lit web components shipped in the HACS bundle. The Home Assistant runtime is simulated locally, so controls are safe to explore and service calls appear in an action log below the card.

## Explore the system

- Use **Controls** to change entity state, values, labels and variants.
- Switch between mobile, tablet and desktop using the viewport toolbar.
- Open a card's **Documentation** tab for configuration and state examples.
- Interactive controls never reach a real Home Assistant instance.

## First components

The initial catalogue covers Hero, Metric, Control, Cover and Appliance. Further cards can reuse the same mock runtime and story template.
